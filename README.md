# trip-map-builder · 出游信息地图生成器

把一堆零散的出游素材（小红书 / 大众点评截图、手打清单、地图收藏夹、文章链接），整理成**一个单文件 HTML**：

> 左侧真实地图（可缩放拖拽）＋ 右侧可独立滚动的清单 ＋ 点任意点看详情与来源截图 ＋ 一键复制名称地址 ＋ 按当前位置算直线距离。

- **单文件交付**：除底图瓦片需联网外零外部依赖，双击即可打开，也可直接发链接给人
- **配置驱动**：一份模板 ＋ 每个目的地一份 `trip.json`，**换城市不需要改代码**
- **两道质量门**：构建期硬断言（不合格直接中止，不做静默降级）＋ 运行时回归探针（59 项断言）
- **坐标可追溯**：每条带坐标的条目都必须留下检索证据（「腾讯地图：XX店（某分店）」），没证据的坐标不允许入库

---

## 这是一个 Agent Skill

本目录是一份可被 Agent 直接加载的技能包，入口是 `SKILL.md`（含 frontmatter 的 `name` / `description`）。

安装：把整个目录放进你的 skills 目录（例如 `~/.workbuddy/skills/trip-map-builder/`），Agent 会在命中触发词时自动加载。

触发词：**做 XX 的出游地图 / 游玩地图 / 美食地图 / 逛吃地图**、把这份清单做成地图、去哪玩怎么整理、旅行清单可视化。

## 目录结构

```
trip-map-builder/
├── SKILL.md                      # 主流程 + 引导剧本（技能入口）
├── GUIDE.md                      # 新人可独立阅读的教程
├── assets/
│   ├── build.py                  # 参数化引擎（含构建期硬断言）
│   ├── templates/index.template.html   # 与地区无关的页面模板
│   └── vendor/leaflet.{js,css}   # 内联用，保证单文件交付
├── examples/kaifeng/             # 完整样例配置（含全部可配项）
│   ├── trip.json
│   ├── data.json                 # 217 条示例数据
│   └── README.md
├── scripts/probe.py              # 通用运行时回归探针
└── reference/
    ├── config.md                 # trip.json 全部字段说明
    ├── data-schema.md            # data.json 字段规范
    ├── geo-verification.md       # 坐标怎么核（三条通道 / 调用示例 / 七步流程 / 陷阱）
    └── quality-gates.md          # 质量门清单与理由
```

## 试跑

```bash
cd examples/kaifeng
python ../../assets/build.py --trip trip.json --check-only          # 只校验（不涉图片，必通过）
python ../../assets/build.py --trip trip.json --out ./index.html   # 生成页面
```

样例目录**不含来源截图**（约 14MB，未随包分发），因此直接生成会出现一条「215 张截图找不到」的告警——这是预期行为，生成出的页面除详情页截图不显示外功能完整。

## 关于示例数据

`examples/kaifeng/` 是开封的完整案例，随包一起公开。其中的**住处条目已完全泛化**（店名 →「住处（示例）」，坐标 → 演示用偏移值），详见该目录的 README。

> 💡 你自己做的时候不必这样——住处**照实标更好用**（店名 + 地址 + 坐标，距离和星标才准）。
> 只有确定页面要对外发布时，才需要处理。规则见 `SKILL.md` 第六节。
